# Buildings / rooftop kit (procedural + CC0 textures)
`rooftop_kit.gd`: static builders — water_tank, antenna, ac_unit, metal_shed (鐵皮加蓋), parapet (tiled 女兒牆), tree, facade_dressing
(balcony slabs + railings on MultiMesh box buildings). Snippets at the top of the file. Textures come from `lib/materials/ambientcg/`
so the project must have the `lib` symlink. Verified on the dream-wings rooftop (i.MX8MP): no measurable FPS change.
